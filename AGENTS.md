# Навигация для агентов

Этот файл для нейросетевого агента, который помогает оператору выделенного сервера Quake III на образах `ghcr.io/doszoner/q3ded`. Справочник написан по-русски, отвечайте оператору на его языке.

## Как читать справочник

- Начните с [README.md](README.md): какие образы описаны, их теги и digest.
- Сверьте тег оператора с [таблицей образов](README.md#образы). Факты проверены на этих тегах. Если у оператора другой тег, скажите ему, что поведение может отличаться.
- Значение слова ищите в [glossary.md](glossary.md). Определение термина есть только там, страницы ссылаются на него.
- Entrypoint образа сам задаёт часть переменных сервера и мода и перекрывает значения из обычных конфигов. Поэтому общие советы по ioquake3, CPMA и OSP из интернета и из оригинальной документации годятся, только если справочник не говорит иначе. Сначала проверьте [зашитые значения](common/pinned.md) и [порядок настроек](common/layers.md#кто-кого-перекрывает).

## Насколько факт проверен

| Пометка в тексте | Что значит |
|---|---|
| «Проверено запуском на `<тег>`» | образ этого тега запускали, результат наблюдали |
| ✓ в таблицах [отказов при старте](troubleshooting.md#отказы-при-старте) | строка получена запуском при условиях, названных в этой строке; на другие моды и условия отметка не распространяется |
| «по коду entrypoint» | сведения взяты из кода entrypoint этого образа; проверка запуском отмечается рядом отдельно |
| «не проверялось», «не проверено» | этот случай не подтверждён проверкой; сохраняйте оговорку в ответе и не достраивайте его догадкой |

Если ответа в справочнике нет, так и скажите оператору и предложите проверить на его сервере: через [rcon](recipes/rcon.md), [консоль](recipes/console.md) или лог.

## Чего здесь нет

Справочник описывает настройки и наблюдаемое поведение сервера со стороны оператора. Устройство служб DosZone, реализация браузерного клиента и исходный код entrypoint в него не входят. Не ищите их и не додумывайте.

## Безопасность

Когда просите у оператора данные для разбора, соблюдайте [правила CONTRIBUTING.md](CONTRIBUTING.md): не просите `rtc.json` и полный вывод ENV, пароли в нужных фрагментах пусть заменит на `CHANGE_ME`.
